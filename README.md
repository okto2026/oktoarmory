# OKTO Armory Website

Ready-to-upload static website for https://oktoarmory.com/

## Files
- index.html — complete responsive homepage
- favicon.svg — browser favicon
- site.webmanifest — site/app metadata
- robots.txt — search crawler instructions
- sitemap.xml — sitemap for search engines
- CNAME — GitHub Pages custom-domain file

## GitHub Pages deployment
1. Create a public GitHub repository (for example: oktoarmory).
2. Upload every file in this folder to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the main branch and /(root), then Save.
6. Set the custom domain to: oktoarmory.com
7. Configure the domain's DNS records at GoDaddy for GitHub Pages.
8. Once DNS resolves and GitHub permits it, enable "Enforce HTTPS".
